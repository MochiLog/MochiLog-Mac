# MochiLog Mac 0.2.26 beta

## 日本語

サポートのデバッグログを開くと長時間待たされる問題を修正しました。保存済みログの読み込み・機能分類をバックグラウンドで行い、大きいログをページ単位で表示します。読み込み中も画面を閉じられ、日付や機能の切り替えに古い読み込み結果が混ざりません。「コピー」は選択した日付・機能の全文を取得します。ログの保存内容やサポート添付、ペアリング、収集・転送方式は変更ありません。

ページ切り替えと読み込み表示は、アプリの8言語に対応しています。

## English

Fixed long waits when opening support debug logs. Saved logs and feature categories now load in the background, while large logs are displayed in bounded pages. The window remains responsive while loading, and stale results cannot overwrite a newer date or category selection. Copy retains the entire selected date/category, not just the visible page. Archive content, support attachments, pairing, and collection/transfer protocols are unchanged.

Loading and pagination controls support all eight app languages.
