# MochiLog Mac 0.2.11 Beta

## 日本語

ウィンドウの×ボタンを押すとMochiLog Macが終了し、ログの自動収集と転送が止まってしまう問題を修正しました。初期設定ではウィンドウを閉じてもメニューバーで動作を続けます。アイコンからウィンドウを再表示でき、「終了」を選ぶと完全に停止します。

「設定 → ウィンドウを閉じたとき」から、×ボタンで完全に終了する動作も選べます。バックグラウンドで動作を続ける設定では、メニューバーのアイコンが常に表示されます。

## English

Closing the MochiLog Mac window could quit the app and stop automatic log collection and transfers. The window now closes while the app keeps running in the menu bar by default. Reopen it from the menu bar icon, or choose **Quit** to stop the app completely.

Under **Settings → When closing the window**, you can instead choose to quit when closing the window. The menu bar icon remains visible whenever background operation is selected.
