# MochiLog Mac 0.2.0 Beta

MochiLog Mac is an experimental companion for iOS/iPadOS 27. It collects eligible iPhone, iPad, and paired Apple Watch analytics logs while the mobile device is unlocked, then securely transfers them when MochiLog is open on that device. Analysis and record storage remain on the iPhone or iPad.

This beta adds the MochiLog app icon, menu bar and login options, pairing progress, copyable diagnostics, and an update checker. Its setup and support screens are available in the same eight languages as MochiLog.

The matching mobile feature is still in development and is not yet in the App Store release. Pairing requires macOS 27, iOS/iPadOS 27, a shared Wi-Fi network, Bluetooth, and an initial OS pairing step. Collection works only while the mobile device is unlocked.

MochiLog Mac 0.2.0ベータ版は、iOS/iPadOS 27向けの開発中の連携アプリです。端末のロック解除中に対象のiPhone・iPad・ペアリング済みApple Watchの解析ログを収集し、MochiLogを開いたときに安全に転送します。解析と記録はiPhone/iPad側で行います。

この版ではアイコン、メニューバー・ログイン時起動の設定、ペアリング進捗、コピー可能な診断ログ、アップデート確認、8言語の案内を追加しました。対応するモバイル機能はまだApp Store版には含まれません。
