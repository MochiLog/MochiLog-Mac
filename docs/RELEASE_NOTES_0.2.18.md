日本語

現在のバッテリー情報を専用タブへ移しました。概要の先頭はペアリング済み端末の一覧になり、接続状態と転送状況を確認しやすくしました。現在値の表・詳細・今すぐ取得／送信は「現在のバッテリー」で利用できます。PC画面からの定期取得はそのタブを表示している間だけ行い、スマホからの更新要求は引き続き受け付けます。

English

Live Battery now has its own tab. Overview starts with the paired-device list so connection and transfer status remain easy to scan. Current values, optional details and Receive/Send Now are available in Live Battery. Desktop viewing refreshes run only while that tab is visible; mobile refresh requests remain supported.
