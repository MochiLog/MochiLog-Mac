# MochiLog Mac 1.0.2

## 日本語

・低速な通信環境で、ログの転送が途中で止まる問題を修正しました。
・一部の環境でApple Watchのログを送信できない問題を修正しました。
・端末の検出と診断サービスへの接続の互換性を改善しました。
・接続や転送に失敗した際の診断情報を改善しました。

既存のペアリングと保存済みログを引き継ぎます。対応環境はmacOS 27以降です。

## English

• Fixed interrupted log transfers on slow connections.
• Fixed an issue that prevented Apple Watch logs from being sent in some environments.
• Improved compatibility with device discovery and diagnostic services.
• Improved diagnostics for failed connections and transfers.

Existing pairings and stored logs are preserved. Requires macOS 27 or later.
