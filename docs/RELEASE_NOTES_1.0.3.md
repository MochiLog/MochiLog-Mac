# MochiLog Mac 1.0.3

## 日本語

・ペアリング時のローカルネットワーク権限の確認と、設定への案内を追加しました。
・無線接続と診断サービスの互換性を改善しました。
・ログ収集に失敗したときの結果表示と診断情報を修正しました。

既存のペアリングと保存済みログを引き継ぎます。対応環境はmacOS 27以降です。

## English

• Added local network permission checks and guidance to Settings during pairing.
• Improved compatibility with wireless connections and diagnostic services.
• Corrected collection failure results and diagnostics.

Existing pairings and stored logs are preserved. Requires macOS 27 or later.
