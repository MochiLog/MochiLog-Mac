# MochiLog Mac 0.2.8 Beta

## 日本語

macOSからiPhone・iPadの解析ログを収集し、MochiLogへ安全に転送するベータ版です。アプリが終了・停止した原因を調べやすくするため、macOSから届いた直近のクラッシュ・ハング診断をMac内に保存するようにしました。サポートメールを作成する際は、従来の接続診断に加えてこの報告を添付できます。自動送信はしません。

初回のUSB信頼設定、QRによるMochiLogペアリング、ロック解除中の収集が必要です。収集・転送の問題はアプリ内のデバッグログとサポート画面から報告できます。

## English

This beta collects analytics logs from an unlocked iPhone or iPad on macOS and transfers them securely to MochiLog. To help diagnose unexpected exits and hangs, the app now retains the latest macOS diagnostic report locally. A user-initiated support email can include it alongside the existing connection report; nothing is sent automatically.

Initial USB trust, MochiLog QR pairing, and an unlocked device are required. Connection or transfer issues can be reported from the in-app debug log and support screen.
