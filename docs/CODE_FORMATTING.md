# コード整形

Swiftは2スペース・100桁を目安に整形します。PythonはRuff 0.14.0で整形します。Swiftの宣言や式を書き換えるルールは整形コマンドでは無効にし、改行・字下げを揃えます。元の `.swift-format` のlint設定はそのまま利用できます。

必要な開発ツールは `swift-format`、Python 3.10以降、`uv` です。Ruffのバージョンはスクリプトで固定しています。アプリ利用者がこれらをインストールする必要はありません。

```sh
python3 scripts/format-code.py
python3 scripts/format-code.py --check
```

Gitが管理するソースと、除外されていない新しいソースが対象です。ビルド生成物・同梱依存ライブラリ・診断データはGitの除外設定に従います。

## 2026-10-19の確認

Swiftの構文を整形前後で比較（配列・辞書の任意の末尾カンマは除外）。暗号化転送・ACK・再送防止・複数端末・保存管理の既存テスト、およびPython 10件が成功。
