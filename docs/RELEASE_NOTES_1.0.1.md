# MochiLog Mac 1.0.1

## 日本語

- ペアリング時の接続準備と、接続できないときの案内を改善しました。
- ペアリング前でもサポート用の情報を作成できるようになりました。
- サポートへ添付する情報を1つのZIPにまとめ、発生日時に応じたログと設定情報を含められるようになりました。
- 連携で問題が起きた際の状況を、より詳しく記録するようにしました。

スマホ版MochiLog 4.1.0とあわせて更新してください。既存のペアリング・設定・保管済みログは引き継ぎます。

## English

- Improved connection readiness during pairing and guidance when a connection cannot be established.
- Support information can now be prepared before pairing is completed.
- Support attachments are bundled into one ZIP with dated logs and relevant settings information.
- Improved diagnostic detail when a connection or pairing fails.

Update alongside MochiLog mobile 4.1.0. Existing pairings, settings and stored logs are preserved.
