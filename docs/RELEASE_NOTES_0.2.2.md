# MochiLog Mac 0.2.2 Beta

Organizes the Mac app into Overview, Devices, Support, and Settings so daily collection and pairing are easier to find. Fixes transfer of Apple Watch analytics logs stored beside same-named iPhone logs. Automated protocol checks cover authentication, replay rejection, separate iPhone and Watch payloads, acknowledgements, and repeat pulls. A physical iPhone 17 received authentic iPhone and Watch logs, then correctly skipped both existing records as duplicates.

Macアプリの画面を「概要・端末・サポート・設定」に整理し、日常の収集操作とペアリングを探しやすくしました。同名のiPhoneログとApple Watchログがある場合に、Watchログの転送トークンを作れない問題を修正しました。認証、再送拒否、両方のログの区別、受信確認、再取得を自動検証しています。iPhone 17実機でもiPhoneとWatchの実ログを受信し、既存記録2件が重複としてスキップされることを確認しました。
