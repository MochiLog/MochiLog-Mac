# MochiLog Mac 0.2.1 Beta

Diagnostic reports now keep the latest events that fit the secure transfer limit, so long sessions do not block iPhone or iPad pairing and log delivery. A new in-app license viewer shows the MochiLog, collector, Sparkle, and bundled Python notices.

MochiLog Mac 0.2.1ベータ版では、診断情報が長くなっても転送上限に収まる最新イベントを送るようにしました。長時間の利用後も、iPhone/iPadとのペアリングやログ転送が診断情報の長さで止まらないようにします。また、アプリ内でMochiLog・収集ツール・Sparkle・Python依存パッケージのライセンス情報を確認できます。
